Olha a image103 e veja algumas coisas que percebi:
- Coluna PARC deve mostrar o numero da parcela daquela linha... no caso dos pedidos feitos no pdv saiu correto, porem no caso dos com origem OS saiu o numero da OS nessa coluna.
- Coluna FORMA é para parecer a forma de pagamento daquela linha, no caso dos pedidos feitos no pdv saiu correto, porem no caso dos com origem OS saiu CONSERTO (que é o TIPO_OS).
- Notei que no caso dos pedidos feitos no pdv, para cada parcela é uma linha, ou seja, se um pedido tem 3 parcelas, serão 3 linhas (com suas formas de pagamento), porem no caso dos com origem OS saiu uma linha para cada pedido. 
Exemplo o pedido 770 (segunda linha no grid com cod_OS 462), ele possui duas parcelas:
SELECT        CODIGO, COD_PEDIDO, COD_OS, NUMERO, DATA, PAGAMENTO, DIAS_ATRAZO, JUROS, MULTA, VALOR, VALOR_FINAL, STATUS, HAVER, HORA, FORMA_PGTO, CODCAIXA, CAIXA, TIPO_CARTAO, TIPO, DESCONTO, OS_ITEM, 
                         COD_FUNCIONARIO
